# ARIN 121 Assignment 3 Travel Planner

This system prompt helps travelers choose destinations, build itineraries, compare transportation and lodging, and estimate costs. It can rank destination fit out of 10, show a destination map where supported, and apply currency and unit preferences.

## How to use it

Paste the contents of system-prompt.md into the system instructions in Google AI Studio Playground and start a new chat. A general request such as “Can you help me plan a trip?” opens the menu.

1. **Plan a trip** to choose a destination or build an itinerary.
2. **Revise an itinerary** to adjust a plan. Share the current plan, what should change, and what should stay fixed. Review the proposed revision and either ask for changes or accept the draft.

Choose by number, by name, or with a clear request in your own words. Ask to switch at any point. The planner carries forward details that still apply.

Live prices, verified schedules, maps, saved defaults, and bookings depend on the tools available in the host environment.
